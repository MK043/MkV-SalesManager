# MKV Auto Stand — Система управління автосервісом та конвеєром робіт

Повнофункціональна виробнича веб-платформа для управління автосервісом, воронкою замовлень, складом, касою та персоналом, брендована у фірмовому стилі **MKV Production**.

---

## 🚀 Основний функціонал системи

1. **Сьогодні (`/today`)**:
   - Денна виручка, кількість оплат, динаміка порівняно з минулим днем (+/- ₴, $, €).
   - 7-денний інтерактивний графік фінансових надходжень.
   - Заборгованість клієнтів із рейтингом найбільших боржників за нарядами.
   - Завантаження цеху: автомобілі в роботі, прострочені терміни, авто на стоянці.
   - Активні майстри на зміні в цеху в реальному часі.

2. **Конвеєр робіт (`/board`)**:
   - 8 виробничих етапів: *Прийомка*, *Діагностика*, *Узгодження робіт*, *Замовлення запчастин*, *Ремонт*, *Контроль якості*, *Мийка*, *Видача*.
   - Картки з українськими номерами (`AO 7788 MK`), маркою, клієнтом, відповідальним майстром та кошторисом.
   - Швидке переведення на наступний етап, откат етапу або переміщення на автостоянку.
   - Фільтрація за майстрами цеху та пошук.

3. **Реєстр замовлень-нарядів (`/orders`)**:
   - Повний пошук за номером наряду, держномером, авто чи клієнтом.
   - Фільтрація за статусами (*Всі*, *У роботі*, *На стоянці*, *Завершені*).
   - Створення нового наряду через модальне вікно прийомки.

4. **Картка замовлення-наряду (`/orders/:id`)**:
   - Інтерактивний степпер 8 етапів із кнопками переведення та відкату.
   - Вкладки:
     - *Загальна картка*: характеристики авто, VIN, дані клієнта, призначення майстра.
     - *Роботи та послуги*: кошторис, додавання робіт, розрахунок вартості.
     - *Запчастини*: перелік деталей, собівартість, ціна продажу, статус постачання.
     - *Платежі*: облік оплат, форми розрахунку (готівка/картка/IBAN), автоматичне формування ПКО.
     - *Чек-лист якості*: інтерактивні пункти контролю з миттєвим збереженням.
     - *Документи*: акти виконаних робіт, рахунки-фактури, діагностичні карти.
     - *Коментарі*: стрічка приміток майстрів.
     - *Історія*: повний аудит-трейл змін наряду.

5. **Онлайн-записи на ремонт (`/bookings`)**:
   - Календар візитів клієнтів, час візиту, послуга, коментарі.
   - Дія в 1 клік: «Оформити прийомку», яка миттєво конвертує запис у новий активний наряд.

6. **Автостоянка сервісу (`/parking`)**:
   - Моніторинг автомобілів, що очікують погодження або запчастин.
   - Кнопка повернення зі стоянки назад у виробничий конвеєр.

7. **Складський облік (`/warehouse`)**:
   - Залишки товарів, SKU, категорії, ціни закупки та продажу.
   - Складські накладні: *Прихід (ПН)*, *Відвантаження в наряд*, *Списання*, *Інвентаризація*.
   - Проведення та скасування проведення документів.

8. **Постачання запчастин (`/parts`)**:
   - Зведена таблиця деталей для всіх автомобілів у ремонті.
   - Фільтрація: *Потрібно замовити*, *Замовлено*, *Прибуло на склад*.
   - Кнопка позначення надходження на склад в 1 клік.

9. **Каса та фінанси (`/cash`)**:
   - Поточний баланс каси, щоденний прихід та витрата.
   - Створення прибуткових (ПКО) та видаткових (РКО) касових ордерів.
   - Облік готівки, банківських карток POS та рахунків IBAN.

10. **Аналітичні звіти (`/reports`)**:
    - Звіт по заборгованостях клієнтів.
    - Виробіток майстрів (замовлення, години, сума робіт, зарплата).
    - Показники майстрів-приймальників (оборот, конверсія).
    - Розрахункова відомість нарахування заробітної плати.
    - Зведений реєстр з експортом у CSV.

11. **Завдання компанії та персональні завдання (`/company-tasks`, `/my-tasks`)**:
    - Постановка внутрішніх доручень, пріоритети, виконавці, статуси.
    - Персональний екран механіка для роботи над закріпленими авто.

12. **Зміни та присутність у цеху (`/shifts`)**:
    - Облік виходу майстрів на зміну, фіксація часу, відкриття та закриття змін.

13. **Співробітники (`/employees`)**:
    - Штат автосервісу, ролі, посади, телефони, системні логіни.

14. **Налаштування (`/settings`)**:
    - Мова: 🇺🇦 Українська (за замовчуванням) та 🇬🇧 English.
    - Валюта: Гривня (₴ UAH), Долар ($ USD), Євро (€ EUR).
    - Колірний режим: Глибока темна тема (MKV Obsidian) та Світла тема.
    - Фірмовий акцент: Оливковий MKV (`#4A5E38`), Пісочний (`#C8AD8D`), тощо.
    - Налаштування етапів конвеєра та матриці прав доступу.

15. **Журнал аудиту (`/audit`)**:
    - Фіксація кожної дії в системі (створення наряду, оплата, зміна етапу, складські документи).

## 🛠️ Запуск та експлуатація

### 1. Встановлення залежностей
```bash
npm install
```

### 2. Запуск у режимі розробки (Hot-Reload)
```bash
npm run server   # Запуск REST API сервера на http://localhost:3001
npm run dev      # Запуск Vite frontend на http://localhost:5173
```

### 3. Збірка та запуск у продакшн-режимі (All-in-One)
```bash
npm run build    # Збірка оптимізованого клієнтського бандла у dist/
npm start        # Запуск повноцінного Express сервера з роздачею SPA та API на http://localhost:3001
```

### 4. Запуск автоматичних тестів
```bash
npm test         # Виконання 11-рівневого тест-сьюту верифікації API, бази даних та асетів
```

## 📁 Структура проєкту

- `server/index.js` — REST API сервер із повною персистентністю (`server/database.json`), логуванням аудиту та роздачею SPA.
- `src/screens/` — 17 повнофункціональних екранів інтерфейсу автосервісу.
- `src/components/` — Модальні вікна, панелі навігації (`Header`, `Sidebar`, `AppLayout`).
- `src/i18n/` — Система локалізації (`uk` / `en`) без російської мови.
- `src/utils/currency.js` — Багатовалютний модуль (UAH, USD, EUR).
- `public/brand/` — Оригінальні логотипи та фавікони MKV Production.
- `test/suite.js` — Набір автоматизованих тестів.
