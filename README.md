## 📌 Про проєкт простими словами

**MkV Sales Manager CRM** — це єдина робоча панель для таргетолога та медіабаєра, яка об'єднує запуск і контроль реклами у **Facebook, Instagram (Meta Ads)** та **TikTok Ads**.

### Яку проблему вирішує проєкт:
1. **Не потрібно відкривати десятки вкладок:** замість перемикання між різними рекламними кабінетами всі ключові цифри (витрати, кількість заявок, окупність ROAS) зведені в один зручний дашборд.
2. **Швидке створення сценаріїв для відео:** вбудована ШІ-студія генерує покадрову розкадровку для Reels та TikTok (хук перших секунд, розкриття проблеми, заклик до дії).
3. **Захист від зливу грошей:** автоматичні правила зупиняють збиткові оголошення, якщо вартість ліда перевищує заданий ліміт.
4. **Контроль вигорання аудиторії:** сервіс відстежує, коли реклама набридає людям, і дозволяє швидко замінити перші 3 секунди (хук) без перезапуску всієї кампанії з нуля.

## 🖥️ Основні модулі платформи

У межах лабораторної роботи спроєктовано 4 робочі екрани та обов'язкове модальне вікно авторизації:

1. **Головна панель аналітики (Analytics Dashboard):**  
   Відображає витрачений бюджет, кількість отриманих лідів, середній ROAS та щоденний графік динаміки трафіку одночасно по Meta та TikTok.
2. **Креативна ШІ-студія (AI Creative Studio):**  
   Генерує готові сценарії для коротких вертикальних відео з таймлайном (0–3с, 4–15с, 16–25с), текстом суфлера та симулятором дикторської озвучки.
3. **Центр управління кампаніями (Campaigns & Media Buying):**  
   Таблиця з усіма активними кампаніями, швидкими перемикачами On/Off та авто-правилами контролю бюджету.
4. **Детектор вигорання аудиторії (Ad Fatigue Detector & Hooks):**  
   Шкала втоми аудиторії, показник утримання уваги (Hold Rate) та кнопка швидкої ротації хуків.
5. **Модуль авторизації (Auth Modal):**  
   Модальне вікно безпечного входу спеціаліста через корпоративний акаунт (Google / Meta OAuth 2.0) або робочу пошту та API-токен.

## 🎨 Робота з макетами у Figma

Усі макети в папці `mockups/` виконані у векторному форматі **SVG** з розміром **1440×960 px** у темній темі:
* Щоб відкрити макет у Figma, створіть новий файл і просто перетягніть (Drag & Drop) будь-який `.svg` файл на робочу область.
* Усі тексти прив'язані до шрифту **Inter**, їх можна вільно редагувати подвійним кліком миші.
* Усі блоки згруповані у зрозумілі фрейми (`Sidebar`, `TopTabBar`, `MainContent`).
