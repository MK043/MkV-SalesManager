# Векторні макети інтерфейсу (SVG / Figma)

У цій папці зібрано 6 ключових векторних макетів платформи «MkV Sales Manager CRM»:

1. `01_Головний_огляд_платформи.svg` — Головне робоче середовище таргетолога (Master Hub).
2. `02_Дашборд_аналітики.svg` — Зведена статистика витрат, ROAS, конверсій та графіки.
3. `03_ШІ_Студія_креативів.svg` — Генерація сценаріїв та розкадровка коротких відео (TikTok / Reels).
4. `04_Кампанії_та_медіабаїнг.svg` — Таблиця кампаній, керування бюджетами та авто-правила.
5. `05_Детектор_вигорання_та_хуки.svg` — Аналіз вигорання аудиторії та швидка ротація хуків.
6. `06_Модальне_вікно_авторизації.svg` — Модальне вікно безпечного входу (OAuth 2.0 / API токен).

### Як відкрити у Figma:
Перетягніть (Drag & Drop) будь-який файл `.svg` у робоче поле Figma. Тексти прив'язані до шрифту Inter і повністю доступні для редагування.
