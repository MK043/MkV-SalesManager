# ІНСТРУКЦІЯ: ЯК ВІДКРИТИ ТА РЕДАГУВАТИ МАКЕТИ У FIGMA

Вітаємо! У цій папці підготовлено векторні макети платформи «MkV Sales Manager CRM», повністю оптимізовані для Figma.

---

### 📂 СТРУКТУРА ФАЙЛІВ У ПАПЦІ:

1. `01_Головний_огляд_платформи (Рис 1.1).svg` — Головне робоче середовище таргетолога (Master Hub).

3. `03_ШІ_Студія_креативів (Рис 2.2).svg` — Генератор сценаріїв та розкадровка коротких відео (TikTok / Reels).
4. `04_Кампанії_та_медіабаїнг (Рис 2.3).svg` — Центр управління кампаніями, бюджетами та авто-правилами.
5. `05_Детектор_вигорання_та_хуки (Рис 2.4).svg` — Аналіз вигорання аудиторії та швидка ротація хуків.

Підпапка `02_Усі_первинні_макети_звіту (Повний набір)` містить повний набір первинних файлів (включаючи CAPI та Audiences).

---

### 🚀 ЯК ДОДАТИ В FIGMA (3 ПРОСТІ КРОКИ):

КРОК 1. Відкрийте Figma (у браузері figma.com або у програмі Figma Desktop).
КРОК 2. Створіть новий файл ("+ New design file").
КРОК 3. Просто ПЕРЕТЯГНІТЬ (Drag & Drop) будь-який або всі файли .svg з цієї папки прямо на робоче поле Figma!
        (Або натисніть у Figma меню: File -> Place image/SVG -> виберіть файли).

---

### ✏️ ЯК РЕДАГУВАТИ У FIGMA:

- РЕДАГУВАННЯ ТЕКСТУ:
  Двічі клікніть лівою кнопкою миші на будь-який напис, заголовок або цифру (шрифт Inter використовується за замовчуванням у Figma, нічого встановлювати додатково не потрібно). Можна вільно міняти назви, прізвище, суми тощо.

- ЗМІНА КОЛЬОРІВ ТА ГРАДІЄНТІВ:
  Виділіть будь-яку картку, кнопку чи фон — на панелі праворуч у розділі "Fill" (Заливка) можна обрати будь-який інший колір або градієнт.

- СТРУКТУРА ШАРІВ:
  Усі блоки згруповані у зручні фрейми (TopTabBar, Sidebar, SubHeader, MainContent, BrandHeader), тому ви легко знайдете будь-який потрібний елемент на лівій панелі шарів.

- ЕКСПОРТ:
  Виділіть готовий екран у Figma, праворуч внизу натисніть "Export" і оберіть потрібний формат: PNG, JPG, SVG або PDF.
